Roblox native models use `.rbxm` (binary) or `.rbxmx` (XML). Studio's 3D Importer can also import `.fbx` and `.obj` mesh files. The native accessory imports without a custom-mesh upload; the optimized FBX/OBJ versions are included for use as MeshParts.

Sign into GitHub, open a file, and click **Download raw file**. Insert the native RBXM/RBXMX with Studio's Insert from File command. The per-model README explains how to attach it to a rig.
